# LedgerQA

RAG agent answering financial questions over SEC filings — see [CONTEXT.md](CONTEXT.md) for domain vocabulary and [.scratch/financebench-rag-agent/spec.md](.scratch/financebench-rag-agent/spec.md) for the spec.

Evaluated against [FinanceBench](financebench/)'s 150 open-source questions.
